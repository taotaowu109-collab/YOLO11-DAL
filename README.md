# YOLO11-DAL

Private working repository for a paper-faithful reimplementation of **YOLO11-DAL: A multi-scale fusion network for target detection in UAV-based power line inspection**.

> **Status:** reconstruction in progress. This repository is a reimplementation from the manuscript and cited source designs, not a claim that the original training source code has been recovered. Exact reproduction of the reported metrics requires verification against the authors' original training artifacts and environment.
